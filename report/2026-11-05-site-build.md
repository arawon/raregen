## 요약

**무엇을:** 목업을 실제 정적 사이트로 옮겨 임시 주소에 배포했다.

**왜:** 사용자와 대표가 실제 화면을 보면서 수정하기 위해서다.

**어떻게:** 공통 부품과 데이터 파일을 Astro로 나누고, `dev` push 시 GitHub Actions로 빌드해 Pages에 배포한다.

목업과 달라진 점:
- 문의 폼 대신 `준비중`을 표시한다.
- AOS 원본을 사용한다.
- 정렬 시 CSS `order`가 아니라 DOM 순서를 바꾼다.
- 제품 사양 팝업은 HTML `dialog`를 사용한다.
- 모바일 메뉴 버튼을 추가했다.
- CTA 문구를 `준비중`에 맞춰 "제품 견적과 실험실 구축 상담을 도와드립니다."로 바꿨다.

자동 테스트 코드는 저장소에 추가하지 않았다.

## 남은 이슈

- 실제 모바일 기기, Safari, 키보드 접근성은 확인하지 못했다. 동작 줄이기 설정도 실제로 켜서 시험하지 않았다.
- 제품 사진의 배경과 해상도가 제각각이다. 특히 50050(검은 배경), AX.MCT-150-C-S(회색 배경).
- 로고와 실험실 사진은 해상도가 낮아 큰 화면에서 흐리다. 실험실 페이지의 큰 사진이 특히 그렇다.
- 저장소가 공개라 제조사 로고와 제품 사진도 공개된다. 사용 조건 확인이 필요하다.
- `DEV_PLAN.md` Phase 3, Phase 4의 대표 확인과 외부 대기 항목.
