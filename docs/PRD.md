# PRD.md

제품 요구사항 문서. 최종 갱신: 2026-11-05 (v0.01)

## 1. 개요

- **프로젝트:** ㈜레어젠(RareGen) 기업 사이트 리뉴얼
- **현재 사이트:** https://www.raregen.co.kr/ (쇼핑몰 기능이 포함된 ASP.NET 사이트)
- **목표:** 쇼핑몰형 사이트를 세련되고 관리 부담이 적은 **정적 기업 사이트**로 전환한다.
- **디자인 참고:** https://decagon.ai/ 의 인상과 GNB 동작을 참고한다. 카피, 로고, 디자인 요소를 복제하지 않는다.
- **운영 주체:** 사용자(저장소 소유자)가 앞으로 사이트와 도메인을 직접 관리한다.
- **언어:** 한국어만 지원한다.

## 2. 범위

### 포함

| 영역 | 내용 |
|---|---|
| 회사소개 | 소개 문구, 사업 영역, 회사 정보 |
| 제품정보 | 취급 브랜드, 마그네틱 비드, 기업 소모성 자재, 제품 목록 |
| 실험실 구축 | 제공 범위, 포트폴리오 |
| 견적 문의 | 당분간 `준비중`으로 표시 (§5.8) |
| 모션 | GNB 애니메이션, Swiper, 스크롤 등장 효과 (§6) |

### 제외 (사이트에 흔적을 남기지 않는다)

- 내방객시스템(QDESK): 메뉴, 배너, 소개 페이지, 문구 전체
- 장바구니, 바로구매, 찜하기, 결제
- 로그인, 회원가입
- 상품평, 상품 Q&A, 배송·교환·환불 안내

## 3. 사용자

기존 사이트 내용을 근거로 다음 사용자를 가정한다. 실제 고객 구성은 확인되지 않았다.

- 시약, 장비, 소모품의 견적이 필요한 연구자
- 소모성 자재를 조달하는 기업 담당자
- 실험실 구축을 검토하는 기관 담당자

## 4. 정보 구조

```text
메인
├ 회사소개

│  ├ 취급 브랜드
│  ├ 마그네틱 비드
│  ├ 기업 소모성 자재
│  └ 제품 목록
├ 실험실 구축
└ [견적 문의] CTA 버튼 (대표번호 함께 표시)
```

- 푸터에는 회사 정보, 사업자등록번호, 메뉴 링크를 둔다.
- 개인정보처리방침은 문의 기능을 공개할 때 함께 만든다.

## 5. 페이지 요구사항

### 5.1 메인
히어로 Swiper(제품, 실험실, 시약·장비), 브랜드 로고 흐름, 사업 영역 4개 카드, PureSeek 강조, 주요 제품 Swiper, 실험실 구축 Swiper, 문의 CTA 순서로 구성한다.

### 5.2 회사소개
문구: "정성과 신뢰를 바탕으로 동행하는 생명공학 파트너", 사업 영역 01~04, 회사 정보(§7).

### 5.3 취급 브랜드
15개 브랜드 로고를 격자로 보여 주고 각 공식 사이트로 연결한다(§8).

### 5.4 마그네틱 비드
PureSeek 소개, 특장점 3개(순수: 국내 기술로 제조 / 합리적인 가격: 레어젠만의 가격 정책 / 우수한 성능: 데이터 비교로 입증), Fig 1·2.

### 5.5 기업 소모성 자재
기존 페이지의 표 이미지를 실제 HTML 표로 바꾼다.

| 상품 유형 | 세부 | 내용 | 상품 예 |

| 공장용품(M.R) | 부자재 | 생산용 보조자재, 가공 없이 사용 또는 단순 가공 후 사용 | Tape류, Tube류, 약품류, Band류, 포장 Box 등 |

### 5.6 제품 목록
- 구매 절차 없이 **9개 제품을 개별 카드로** 보여 준다.
- 카드: 사진, 분류, 모델명, 제품명, 가격, 사양 보기
- 카드를 누르면 사양 팝업을 열고 `이 제품 견적 문의`로 연결한다.
- 정렬 4종: 인기상품순, 최근상품순, 낮은가격순, 높은가격순
- **정렬을 바꾸면 카드가 새 위치로 이동하는 모습이 보여야 한다.**
- 가격은 일단 표시한다. 대표 확인 후 유지 여부를 정한다.

### 5.7 실험실 구축
설계·시공 통합 컨설팅, 제공 범위 4개, 포트폴리오(Clean Room 2장, Lab 4장).

### 5.8 견적 문의
- **현재 요구사항:** 문의 폼 자리에 `준비중`을 표시한다. 입력 폼과 발송 기능은 만들지 않는다.
- GNB의 `견적 문의` 버튼과 각 페이지의 문의 CTA는 이 페이지로 연결한다.
- 대표번호와 이메일은 계속 보여 주어 연락 경로를 유지한다.
- 이후 문의 기능을 열 때의 폼 항목: 제목(상품명), 이름, 연락처, 이메일, 문의 내용, 개인정보 수집 동의. 수신 메일은 `jhyoon@raregen.co.kr`로 통일한다.

## 6. 디자인·모션 요구사항

- 페이지는 단순해도 **잘 짜인 레이아웃**으로 보여야 한다. 공통 그리드, 구분선, 일관된 섹션 구조를 사용한다.
- 화면이 정적으로 보이지 않도록 애니메이션을 적극 활용한다.
- GNB에는 아이콘과 애니메이션을 넣는다.
- 시스템의 "동작 줄이기" 설정을 존중한다.
- 세부 값은 `ARCHITECTURE.md` §3을 따른다.
